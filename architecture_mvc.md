Архитектура MVC для приложения "Список задач"



1\. Model (Модель)

Отвечает за данные и бизнес-логику.

\- Класс `Task`: описание задачи (id, title, status).

\- Класс `Database`: подключение к SQLite, методы `save()`, `get\_all()`.

\- Валидация данных (например, нельзя создать задачу с пустым названием).



2\. View (Представление)

Отвечает за отображение данных пользователю.

\- HTML-шаблоны Jinja2 (для веб-версии).

\- JSON-ответы (если это REST API).

\- Отображение списка задач и кнопок управления.



3\. Controller (Контроллер)

Связывает Модель и Представление.

\- Обрабатывает запросы пользователя (GET, POST).

\- Вызывает методы Модели.

\- Передает данные в Представление.

\- Пример: маршруты Flask/FastAPI.



Структура проекта

\- /models/task.py

\- /views/templates/index.html

\- /controllers/task\_controller.py

\- main.py (точка входа)
